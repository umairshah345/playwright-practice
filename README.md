# Playwright Automation Practice

## About Project

This project is created to practice and demonstrate
Web UI Automation and API Testing using Playwright.

## Tools & Technologies

- Playwright
- JavaScript
- Node.js
- Git & GitHub
- VS Code

## Testing Covered

### UI Automation

- Login Testing
- Products Page Validation
- Add to Cart
- Product Sorting
- Logout Testing

### API Automation

- GET Request
- POST Request
- PUT Request
- DELETE Request
- API Status Code Validation
- API Response Validation

## Project Structure

- tests/
- pages/
- utils/
- playwright.config.ts

## How to Run Tests

Install dependencies:

npm install

Run all tests:

npx playwright test

Run tests in headed mode:

npx playwright test --headed

View HTML Report:

npx playwright show-report
